Frequently Asked Questions

Do I need an active internet connection to use CultureCode?
No! CultureCode comes pre-loaded with an offline database containing cultural etiquette and key laws for popular destinations. You only need a network connection if you wish to search for and download rules for a new country.
How does the online country rules generator work?
When you search for a new destination, the app queries Wikipedia's open API to fetch relevant cultural extracts. It then passes this context to Google's Gemini AI to parse, translate, and compile it into standardized rule cards.
Why does the online download fail?
CultureCode uses the free-tier Google Gemini API to dynamically generate cards for new countries. Please make sure that you have inserted a valid, free developer API key from Google AI Studio into NetworkManager.swift inside your app bundle.
Is my search history or personal data tracked?
Absolutely not. CultureCode stores all downloaded country profiles locally on your device's sandboxed storage. No user accounts are required, and no tracking services are integrated.
